# Aulas de Java — PIBID

Repositório dedicado à organização de aulas, exemplos de código e atividades práticas de programação em Java desenvolvidos no contexto do Programa Institucional de Bolsa de Iniciação à Docência (PIBID).

O projeto tem como objetivo apoiar o ensino e a aprendizagem de programação por meio de exemplos práticos, atividades didáticas e propostas que aproximam os conceitos da Computação de situações do cotidiano.

## Sobre o projeto

Este repositório reúne materiais desenvolvidos para apoiar atividades educacionais na área de Computação, com foco no ensino de programação utilizando Java.

Além de apresentar conceitos da linguagem, a proposta busca tornar o aprendizado mais acessível por meio de exercícios, resolução de problemas, atividades práticas e estratégias didáticas que incentivam a participação dos estudantes.

O repositório também representa um espaço de organização e compartilhamento dos materiais produzidos durante a experiência de iniciação à docência, permitindo consultar, reutilizar e aprimorar as atividades desenvolvidas.

## Objetivos

- Apoiar o ensino de programação utilizando Java.
- Organizar exemplos de código e materiais desenvolvidos durante as aulas.
- Desenvolver o raciocínio lógico e o pensamento computacional.
- Relacionar conceitos de programação a problemas e situações reais.
- Explorar metodologias ativas e atividades práticas no ensino de Computação.
- Integrar programação, Inteligência Artificial e Educação Midiática às práticas pedagógicas, quando pertinente.
- Contribuir para a formação docente por meio do planejamento, da aplicação e do aprimoramento de aulas.

## Metodologia de ensino

As atividades são pensadas para aproximar os estudantes dos conceitos de programação por meio de explicações, exemplos e experimentação prática.

Entre as estratégias que podem ser exploradas estão:

- **Aprendizagem prática:** construção e execução de pequenos programas.
- **Resolução de problemas:** identificação de erros e desenvolvimento de soluções.
- **Aprendizagem colaborativa:** troca de ideias e resolução de desafios em grupo.
- **Metodologias ativas:** atividades que incentivam a participação dos estudantes.
- **Educação Midiática e Inteligência Artificial:** análise crítica de informações, códigos e respostas produzidas por ferramentas de IA.


## Como utilizar o repositório

### 1. Clone o repositório

```bash
git clone https://github.com/DaviidCarvallho/aulas_de_Java_PIBID.git
```

### 2. Acesse a pasta

```bash
cd aulas_de_Java_PIBID
```

### 3. Abra os arquivos

Abra o projeto em uma IDE compatível com Java, como Visual Studio Code, IntelliJ IDEA ou Eclipse, ou consulte os arquivos diretamente pelo GitHub.

### 4. Execute os exemplos

Para executar os programas, verifique se o JDK está instalado e configurado. Em arquivos Java independentes, você pode utilizar o terminal:

```bash
javac NomeDaClasse.java
java NomeDaClasse
```

Substitua `NomeDaClasse` pelo nome da classe pública presente no arquivo, sem a extensão `.java`.

Alguns exemplos podem depender de outras classes, bibliotecas ou configurações específicas. Nesses casos, siga as instruções correspondentes à atividade.
